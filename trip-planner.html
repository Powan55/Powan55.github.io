Design choices

Static hosting
Next.js exports the app to GitHub Pages. The deployed interface does not need a Next.js server.
Local storage first
Plans use localStorage and photos use IndexedDB. Keeping that data on the device supports offline use. Browser data can be cleared, so local storage has limits as a long-term backup.
Optional sync
The Firestore layer stays inactive without Firebase configuration. Storage and sync are separate parts of the app; the deployed version uses sign-in.
Cached app shell
A service worker caches the interface for later offline use. That requires an initial load online. A cached shell alone does not guarantee that external map tiles are available offline.

Before a release

Playwright browser tests, Vitest unit tests and axe-core accessibility checks run in GitHub Actions. A version gate blocks publishing without a version bump.

The repository contains the implementation and test suites. Screenshots show the interface; they do not replace trying the app.
