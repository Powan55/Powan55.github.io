Nepal × Japan Trip Planner Featured

Solo build · v7.8.0

An installable trip planner that keeps working with no signal, built for a 32-day trip across Nepal and Japan.

Why I built it

Planning the trip meant notes, spreadsheets, screenshots and map pins in separate places, and none of it worked on a phone in Kathmandu with no signal.

What the tests cover

  • 107 Playwright spec files
  • 570+ e2e cases
  • 311 Vitest files
  • axe-core in 42 specs

How it works

  • Static export on GitHub Pages. A hand-rolled service worker precaches the app shell, so it installs to a home screen and runs offline.
  • Plans live in localStorage. A Firestore mirror turns on only when a Firebase config exists, so the app needs no backend.
  • The map is MapLibre on OpenFreeMap tiles.
  • Every PR runs typecheck, ESLint with zero warnings, Vitest, a production build, byte budgets and a Firestore rules emulator check, plus Playwright end-to-end and visual jobs. A release gate blocks publishing without a new version, and a smoke test hits the live site after each deploy.
